After previously seeing that MySQL didn't return any results on Q11, I decided to double check my queries when possible with the Excel raw data. While working on Q13 I noticed the results differed. After reviewing and talking it out with Copilot, I found that MySQL imported minutes_since_last_transaction as integers and was truncating the decimals (2.1 into 2, and 1.8 into 2 for example). Because of this the results will differ from the raw data.
